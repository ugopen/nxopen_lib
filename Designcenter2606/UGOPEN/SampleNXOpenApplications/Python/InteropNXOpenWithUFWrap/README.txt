------------------------------------------------------------------------------------
                        InteropNXOpenWithUFWrap Example
------------------------------------------------------------------------------------

-----------
Description
-----------

This Sample program demonstrates the interoperability of NXOpen and NXOpen.UF

--------------
Files required
--------------

   1. InteropNXOpenWithUFWrap.py

----------------------------
Settings before Launching NX
----------------------------
    None

----------------------------
Settings after Launching NX
----------------------------
1. Change the Role to Advanced.

-----------------------
Example execution steps
-----------------------
   1. Start NX.
   
   2. In the Tools tab, click Play Journal

   3. Click Browse, then browse to this directory

   4. Change the "Files of type" dropdown to "Python Files (*.py)" and click ok.

   5. Click Run
	
      The part file InteropNXOpenWithUFWrap.prt is created in this directory.
