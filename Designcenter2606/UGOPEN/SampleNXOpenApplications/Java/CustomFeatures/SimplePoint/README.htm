SimplePoint

This example demonstrates how a Custom feature "Simple Point" can be implemented. 

Build Steps

The custom feature consists of two parts: Core and UI. Both parts must be built separately.

Build instructions for each part are provided in the following locations:

  • Build instructions for Core
  • Build instructions for UI

After completing these steps, you should have the following files ready to be executed in NX:

  • SimplePointCore.jar and SimplePointUI.jar

Settings before Launching NX

The library SimplePointCore.jar and SimplePointUI.jar along with files CustomFeatureConfiguration.xml and SimplePointUI.dlx, must be placed in one of the following locations:

  1. $UGII_USER_DIR/application
  1. For released applications, using the environment variable UGII_CUSTOM_DIRECTORY_FILE is highly recommended. This variable is set to a full directory path to a file containing a list of root directories for all custom applications. e.g., UGII_CUSTOM_DIRECTORY_FILE=<NX install directory>\ugii\menus\custom_dirs.dat

Note: The entry in UGII_CUSTOM_DIRECTORY_FILE should specify the parent directory of the application folder where the executables and other files are placed. For example, if the executables and files are located in <user_custom_dir>\application, then the entry in UGII_CUSTOM_DIRECTORY_FILE should be <user_custom_dir>.

Settings after Launching NX

None.

Example execution steps

  1. Start NX.
  1. Open any part file.
  1. In NX, go to File - Execute - NX Open, select SimplePointUI.jar, and press Ok.  The SimplePointUI dialog will be displayed on the screen.
  1. Provide the input coordinates to create a Simple Point feature.
  1. Dialog OK/Apply creates the Simple Point.
