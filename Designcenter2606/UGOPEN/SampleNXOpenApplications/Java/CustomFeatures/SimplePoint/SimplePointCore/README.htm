SimplePointCore

This example demonstrates the core logic for the "Simple Point" custom feature. 

Files required

  1. SimplePointCore.java
  2. CustomFeatureConfiguration.xml
  3. Makefile_win

These files are located at $UGII_BASE_DIR/ugopen/SampleNXOpenApplications/Java/CustomFeatures/SimplePoint/SimplePointCore

Build Steps

Windows
  1. Open an NX command prompt window and navigate to SimplePointCore source directory.
  1. Execute the following command: "nmake -f Makefile_win"
  1. This will create SimplePointCore.jar in the current directory.

Unless noted otherwise, the commands in these instructions must be run from an NX command prompt.  See the general notes of the examples for instructions on how to start an NX command prompt.

Example execution steps

To execute the created jar file, please follow the steps provided in the Execute Simple Point.
